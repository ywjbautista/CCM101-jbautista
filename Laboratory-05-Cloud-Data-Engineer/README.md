# Laboratory Activity 5 - The Cloud Data Engineer

## Mission Overview

In this laboratory, I learned about cloud storage by deploying MinIO using Docker. Instead of only reading about Object Storage, I was able to create a working storage environment, access it through a browser, create a bucket, and upload a file.

## Objectives

- Compare Block, File, and Object Storage.
- Understand the purpose of Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO web console through port 9001.
- Create a storage bucket.
- Upload a file as an object.
- Document the activity using Markdown and GitHub.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- Git and GitHub
- Web Browser
- Markdown

## Skills Learned

I learned that different storage types are useful for different kinds of workloads. I also learned how Docker can be used to deploy an object storage service like MinIO. Through the activity, I practiced port mapping, accessing a containerized service through a browser, creating a bucket, and uploading an object. I also encountered an image-pull problem during the deployment, which helped me practice reading terminal errors and finding a working way to continue the activity.
