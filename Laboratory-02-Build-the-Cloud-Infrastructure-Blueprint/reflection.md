# Mission Reflection

## What did you learn from investigating the Linux environment?

Investigating the Linux environment made me realize that a lot of information about a server can be checked using only a few terminal commands. At first, the outputs looked technical and unfamiliar to me, but as I used each command, I started to understand what information I was looking for. I learned how to check the operating system, kernel, CPU, memory, storage, hostname, and IP address.

## How do compute, storage, and networking resources work together?

I understood these components better when I stopped looking at them as separate terms. Compute handles the processing of tasks, storage keeps the files and data, and networking provides the connection needed for communication. Together, they allow a cloud system to process requests, access data, and communicate with users.

## What did you learn from comparing AWS, Azure, and Google Cloud Platform?

The comparison showed me that AWS, Azure, and Google Cloud Platform have similar core services but use different names and technologies. I also learned that choosing a provider is not only about which one is popular, but also about which services are more appropriate for an organization's needs.

## Which cloud infrastructure component do you think is the most important and why?

For me, networking is the most important because it connects the different parts of the cloud environment. Compute and storage are necessary, but users and systems still need a network to communicate and access those resources.

## How can you apply what you learned to real-world cloud systems?

I can apply what I learned when working with Linux servers or cloud platforms in future activities. Instead of seeing cloud computing only as an online service, I now have a clearer idea of the actual resources working behind it. This activity gave me basic skills that I can continue developing as I learn more about cloud infrastructure.
