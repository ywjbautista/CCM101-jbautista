# Laboratory 01: Welcome to the Cloud

## Mission Overview
This laboratory activity introduced me to a Linux cloud environment using KillerCoda. I learned how to use basic Linux commands, create a user account, check system information, and organize files and directories.

## Objectives
- Explore a Linux cloud environment.
- Learn basic Linux terminal commands.
- Create and use a new Linux user account.
- Check Linux system information.
- Create and organize directories and Markdown files.
- Create a GitHub repository for laboratory activities.

## Activities Performed
I launched Ubuntu 24.04 using KillerCoda and created a new user account named jbautista. I checked the current username, working directory, and hostname. I also checked the Linux distribution, kernel version, CPU information, memory, and available disk space. After that, I created Documents, Notes, Reports, and Screenshots directories and created an about-me.md file inside the Notes directory.

## Linux Commands Used
- `sudo useradd` - creates a new user account.
- `sudo passwd` - sets a password for a user.
- `su` - switches to another user account.
- `whoami` - shows the current username.
- `pwd` - shows the current working directory.
- `hostname` - shows the system hostname.
- `cat /etc/os-release` - shows Linux distribution information.
- `uname -r` - shows the kernel version.
- `lscpu` - shows CPU information.
- `free -h` - shows memory information.
- `df -h` - shows disk space information.
- `mkdir` - creates directories.
- `cd` - changes the current directory.
- `ls` - lists files and directories.
- `nano` - creates or edits text files.
- `cat` - displays the contents of a file.

## Skills Learned
I learned how to navigate a Linux terminal, use basic Linux commands, create and manage files and directories, check system information, and use Markdown for documentation.
