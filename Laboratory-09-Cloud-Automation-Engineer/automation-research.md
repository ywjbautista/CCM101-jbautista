# Automation Research

## 1. Bash Script

A Bash script is a text file containing commands that the Bash shell executes in sequence. The `#!/bin/bash` line, called the shebang, identifies the interpreter that should run the script.

## 2. Variables

Variables store values, such as directory paths, so they can be reused in a script. A variable like `$BACKUP_DIR` makes it easier to update the backup location without changing every command that uses it.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script at a specified time. It helps cloud operations by automating repetitive tasks, such as backups, without requiring someone to start them manually.
