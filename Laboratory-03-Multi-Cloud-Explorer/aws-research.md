# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides services for computing, storage, networking, databases, security, artificial intelligence, and other technology needs. Organizations can use these cloud services without having to maintain all computing infrastructure on their own.

## Global Infrastructure

AWS has a global infrastructure composed of Regions and Availability Zones. A Region is a separate geographic area, while Availability Zones are isolated locations within a Region. AWS currently spans 39 geographic Regions and 124 Availability Zones.

## Cloud Management Console

The AWS Management Console is a web-based interface for accessing and managing AWS services and cloud resources. It allows users to work with different AWS services through a graphical interface.

## Four Core Services

### Amazon EC2
Amazon Elastic Compute Cloud (EC2) provides virtual computing resources that can be used to run applications and workloads.

### Amazon S3
Amazon Simple Storage Service (S3) provides object storage for files, application data, backups, and other digital content.

### Amazon VPC
Amazon Virtual Private Cloud (VPC) allows users to create and manage virtual networks for their AWS resources.

### AWS IAM
AWS Identity and Access Management (IAM) helps manage access to AWS services and resources through users, roles, and permissions.

## Three Advantages

1. **Wide Range of Services** - AWS provides many cloud services for computing, storage, networking, databases, security, and other technology needs.
2. **Global Infrastructure** - AWS has Regions and Availability Zones located in different parts of the world.
3. **Scalability** - Organizations can adjust their cloud resources based on changing requirements and workloads.

## Typical Enterprise Use Cases

AWS can be used by enterprises for hosting websites and applications, storing and backing up data, running databases, managing cloud networks, and supporting scalable business workloads.
